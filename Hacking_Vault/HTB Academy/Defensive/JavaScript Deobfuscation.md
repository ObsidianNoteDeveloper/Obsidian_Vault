# Introducción 

La desofuscación de código es una habilidad importante que debemos aprender si queremos ser competentes en el análisis de código y la ingeniería inversa (reverse engineering).

Se tratarán los siguientes temas:

- Localización de código JavaScript
- Introducción a la ofuscación de código
- Cómo desofuscar código JavaScript
- Cómo decodificar mensajes codificados
- Análisis de código básico
- Envío de peticiones HTTP básicas
