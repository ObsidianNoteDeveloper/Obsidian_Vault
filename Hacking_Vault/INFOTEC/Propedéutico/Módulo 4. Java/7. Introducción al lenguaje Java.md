
# Fundamentos del Lenguaje Java

## El origen de Java

Java es un lenguaje de programación de propósito general que fue diseñado con el objetivo de crear aplicaciones que pudieran ejecutarse en diferentes plataformas sin necesidad de modificar su código fuente. Su filosofía se resume en la frase **"Write Once, Run Anywhere" (Escribe una vez, ejecuta en cualquier lugar)**, lo que significa que un programa desarrollado en Java puede ejecutarse en cualquier sistema operativo que cuente con una Máquina Virtual de Java (JVM, _Java Virtual Machine_).

Java fue creado por **James Gosling**, junto con **Mike Sheridan** y **Patrick Naughton**, mientras trabajaban en Sun Microsystems. Actualmente, Java es propiedad de Oracle Corporation después de la adquisición de Sun Microsystems en 2010.

## Historia de Java (1991 - 1995)

El desarrollo de Java comenzó en **1991** como parte del llamado **Proyecto Green**, cuyo propósito era desarrollar software para dispositivos electrónicos inteligentes, como televisores interactivos y electrodomésticos. Inicialmente, el lenguaje recibió el nombre de **Oak**, inspirado en un árbol de roble ubicado frente a la oficina de James Gosling.

Sin embargo, el nombre Oak ya estaba registrado comercialmente, por lo que en **1995** fue renombrado como **Java**, inspirado en el café de Java que consumía el equipo de desarrollo.

Durante esos años ocurrió la siguiente evolución:

|Año|Evento|
|---|---|
|1991|Inicio del Proyecto Green en Sun Microsystems.|
|1992|Se desarrolla el lenguaje Oak y la primera versión de la JVM.|
|1994|Se observa el enorme crecimiento de Internet y se adapta Java para aplicaciones web.|
|1995|Se presenta oficialmente Java al público con el nombre definitivo de Java.|

El éxito de Java fue impulsado por el crecimiento de Internet, ya que permitía desarrollar aplicaciones que podían ejecutarse en diferentes computadoras independientemente del sistema operativo.

# Características de Java

Java posee varias características que lo han convertido en uno de los lenguajes de programación más utilizados durante décadas.

|Característica|Descripción|
|---|---|
|Orientado a objetos|Todo se organiza mediante clases y objetos, facilitando la reutilización del código.|
|Robusto|Incluye manejo de excepciones, recolección automática de basura (Garbage Collector) y comprobación de errores.|
|Portátil|El mismo programa puede ejecutarse en Windows, Linux o macOS gracias a la JVM.|
|Seguro|Incorpora mecanismos que reducen accesos no autorizados a memoria y ejecución de código malicioso.|
|Multihilo (Multithreading)|Puede ejecutar varias tareas simultáneamente dentro del mismo programa.|
|Simple|Su sintaxis es similar a C y C++, pero elimina características complejas como la manipulación directa de memoria mediante punteros.|
|Alto rendimiento|Aunque es interpretado por la JVM, utiliza compilación JIT (Just In Time), mejorando considerablemente su velocidad.|

Estas características hacen que Java sea una excelente opción para desarrollar aplicaciones empresariales, móviles, de escritorio, web y sistemas distribuidos.

# ¿Cómo funciona Java?

Java no se ejecuta directamente sobre el sistema operativo como ocurre con otros lenguajes compilados.

El proceso de ejecución consta de varias etapas:

1. El programador escribe el código fuente con extensión **.java**.
    
2. El compilador (`javac`) convierte ese código en **Bytecode** (.class).
    
3. La **JVM** interpreta o compila ese Bytecode.
    
4. Finalmente el programa se ejecuta sobre cualquier sistema operativo que tenga instalada una JVM.
    

El flujo puede representarse así:

```text
Código Fuente (.java)
          │
          ▼
 Compilador (javac)
          │
          ▼
 Bytecode (.class)
          │
          ▼
 JVM (Java Virtual Machine)
          │
          ▼
 Programa en ejecución
```

Gracias a este proceso, el mismo archivo `.class` funciona en Windows, Linux y macOS sin volver a compilar.

# Estructura básica de un programa Java

Todo programa Java está organizado mediante clases.

La estructura mínima es la siguiente:

```java
public class HolaMundo {

    public static void main(String[] args) {

        System.out.println("Hola Mundo");

    }

}
```

Cada elemento tiene una función específica.

|Elemento|Función|
|---|---|
|`public class HolaMundo`|Declara una clase llamada HolaMundo.|
|`{ }`|Delimitan el inicio y fin de bloques de código.|
|`main()`|Es el método principal donde inicia la ejecución del programa.|
|`System.out.println()`|Imprime información en la consola.|

El método `main()` siempre tiene la siguiente firma:

```java
public static void main(String[] args)
```

Esta firma permite que la JVM identifique el punto de inicio del programa.

# Identificadores

Los identificadores son los nombres que reciben las variables, métodos, clases y otros elementos del programa.

Java establece reglas para nombrarlos correctamente.

|Regla|Ejemplo|
|---|---|
|Deben comenzar con una letra, `_` o `$`|`edad`, `_contador`|
|No pueden iniciar con números|❌ `1edad`|
|Pueden contener números después del primer carácter|`edad1`|
|Son sensibles a mayúsculas y minúsculas|`Nombre` y `nombre` son diferentes.|
|No pueden utilizar palabras reservadas|❌ `class`, `while`|

Ejemplos válidos:

```java
int edad;
double salarioMensual;
String nombreCompleto;
```

Ejemplos incorrectos:

```java
int 5edad;
double class;
String nombre-completo;
```

## String

Aunque muchos principiantes lo consideran un tipo primitivo, **String no es un dato primitivo**, sino una **clase** que representa cadenas de texto.

```java
String nombre = "Raúl";
```

Los objetos `String` permiten realizar operaciones como obtener la longitud del texto, convertir a mayúsculas o buscar caracteres.

## Concatenación

El operador `+` también sirve para unir textos.

```java
String nombre = "Ana";

```


# Conversión de datos

En muchas ocasiones es necesario convertir un tipo de dato en otro.

## Widening (Conversión implícita)

Ocurre automáticamente cuando se convierte un dato pequeño a otro de mayor capacidad.

```java
int numero = 50;

double decimal = numero;
```

No existe riesgo de pérdida de información.

---

## Cast (Conversión explícita)

Cuando se convierte un dato grande a uno más pequeño es necesario realizar un cast.

```java
double precio = 15.99;

int entero = (int) precio;
```

Resultado:

```text
15
```

En este caso se pierde la parte decimal.

---

## Conversión a texto

Cualquier dato puede convertirse a una cadena.

```java
int edad = 25;

String texto = String.valueOf(edad);
```

También puede realizarse mediante concatenación:

```java
String texto = edad + "";
```

Aunque esta segunda técnica funciona, se recomienda utilizar `String.valueOf()` por ser más clara y eficiente.

# Condicionales

Las estructuras condicionales permiten que el programa tome decisiones dependiendo del cumplimiento de una condición.

La estructura más común es `if`.

```java
int edad = 20;

if (edad >= 18) {
    System.out.println("Mayor de edad");
}
```

También puede utilizarse `if-else`.

```java
if (edad >= 18) {
    System.out.println("Puede votar");
} else {
    System.out.println("No puede votar");
}
```

Cuando existen múltiples alternativas puede utilizarse `switch`.

```java
int opcion = 2;

switch(opcion){

    case 1:
        System.out.println("Nuevo");
        break;

    case 2:
        System.out.println("Guardar");
        break;

    default:
        System.out.println("Salir");
}
```

# Bucles o Loops

Los bucles permiten repetir un conjunto de instrucciones mientras una condición sea verdadera o durante un número determinado de iteraciones.

El ciclo `for` se utiliza cuando se conoce la cantidad de repeticiones.

```java
for(int i = 1; i <= 5; i++){

    System.out.println(i);

}
```

El ciclo `while` se utiliza cuando la condición se evalúa antes de ejecutar el bloque.

```java
int contador = 1;

while(contador <= 5){

    System.out.println(contador);

    contador++;

}
```

El ciclo `do-while` ejecuta el bloque al menos una vez, ya que la condición se verifica al final.

```java
int numero = 1;

do{

    System.out.println(numero);

    numero++;

}while(numero <= 5);
```

La elección entre `for`, `while` y `do-while` depende del problema que se desea resolver. Si se conoce previamente el número de repeticiones, normalmente se utiliza `for`; cuando la cantidad de iteraciones depende de una condición que puede cambiar durante la ejecución, suele emplearse `while`; y cuando es necesario ejecutar el código al menos una vez, la mejor opción es `do-while`.
