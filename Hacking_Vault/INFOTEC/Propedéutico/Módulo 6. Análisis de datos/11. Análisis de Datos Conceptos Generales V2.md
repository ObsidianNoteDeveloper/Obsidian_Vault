
# Análisis de Datos

El **análisis de datos** es el proceso mediante el cual se recopilan, organizan, limpian, transforman e interpretan datos con el objetivo de obtener información útil que permita comprender un problema, descubrir patrones y apoyar la toma de decisiones. Actualmente es una disciplina fundamental en áreas como los negocios, la investigación científica, la medicina, la ingeniería, las finanzas, la ciberseguridad y la inteligencia artificial.

La idea principal del análisis de datos es **convertir datos sin procesar en conocimiento útil**. Los datos por sí solos representan hechos o mediciones aisladas; sin embargo, cuando se analizan correctamente, permiten identificar tendencias, realizar predicciones y comprender el comportamiento de personas, procesos o sistemas.

Este proceso generalmente sigue varias etapas: la recolección de datos, la limpieza de información errónea o incompleta, la exploración de los datos mediante estadísticas y visualizaciones, el análisis utilizando diferentes técnicas y, finalmente, la interpretación de los resultados para obtener conclusiones que ayuden a resolver un problema.

---

# Conjuntos de datos (Datasets)

Un **conjunto de datos** o **dataset** es una colección organizada de información que contiene múltiples registros sobre un mismo tema. Generalmente se representa en forma de tabla, donde las filas corresponden a los elementos observados y las columnas representan las características o atributos de esos elementos.

Por ejemplo, una universidad puede almacenar un conjunto de datos con información de sus estudiantes. Cada fila representa un estudiante diferente y cada columna contiene información específica como el nombre, edad, carrera, promedio o semestre.

|Matrícula|Nombre|Edad|Carrera|Promedio|
|---|---|---|---|---|
|1001|Ana|20|Sistemas|9.4|
|1002|Luis|22|Industrial|8.7|
|1003|María|19|Sistemas|9.8|

En ciencia de datos es común trabajar con conjuntos que contienen desde cientos hasta millones de registros. Mientras mayor sea la cantidad y calidad de los datos disponibles, más precisos podrán ser los análisis y modelos que se desarrollen.

---

# Instancias

Una **instancia** representa una observación individual dentro de un conjunto de datos. En una tabla corresponde a una **fila completa**, ya que contiene todos los valores asociados a un solo elemento.

Por ejemplo, en el conjunto de datos anterior, la información correspondiente a "Ana" constituye una instancia porque reúne todas las características de un estudiante específico.

|Instancia|Edad|Carrera|Promedio|
|---|---|---|---|
|Ana|20|Sistemas|9.4|

Dependiendo del problema que se esté resolviendo, una instancia puede representar una persona, un automóvil, una venta, una imagen, una transacción bancaria, un paciente o incluso una conexión de red en un sistema de ciberseguridad.

En aprendizaje automático, cada instancia constituye un ejemplo que el algoritmo utilizará para aprender patrones.

---

# Variables

Las **variables** son las características o atributos que describen a cada instancia dentro del conjunto de datos. Cada variable corresponde a una columna de la tabla y almacena un tipo específico de información.

Las variables permiten responder preguntas acerca de los datos y son fundamentales para construir modelos estadísticos o de inteligencia artificial.

Por ejemplo:

|Variable|Valor|
|---|---|
|Edad|21|
|Carrera|Ingeniería|
|Promedio|9.2|

Cada variable posee un tipo de dato que determina las operaciones que pueden realizarse sobre ella.

---

# Variables numéricas

Las **variables numéricas** contienen valores cuantitativos expresados mediante números. Permiten realizar operaciones matemáticas como sumar, restar, calcular promedios, desviaciones estándar o porcentajes.

Estas variables representan cantidades medibles.

Ejemplos:

|Variable|Ejemplo|
|---|---|
|Edad|20 años|
|Salario|$18,500|
|Peso|72 kg|
|Temperatura|24.5 °C|
|Promedio escolar|9.4|

Las variables numéricas suelen clasificarse en dos grupos.

|Tipo|Características|Ejemplo|
|---|---|---|
|Discretas|Solo toman valores enteros contables|Número de hijos, cantidad de computadoras|
|Continuas|Pueden tomar cualquier valor dentro de un intervalo|Peso, altura, temperatura|

---

# Variables categóricas

Las **variables categóricas** describen cualidades o características que no representan cantidades numéricas, sino categorías o grupos.

Aunque algunas categorías puedan representarse mediante números, esos números funcionan únicamente como etiquetas y no tienen significado matemático.

Ejemplo:

|Alumno|Carrera|
|---|---|
|Ana|Sistemas|
|Luis|Mecatrónica|
|Pedro|Industrial|

Las variables categóricas se clasifican en tres tipos principales.

---

## Variables binarias

Las variables binarias únicamente poseen **dos posibles valores**.

Generalmente representan respuestas de tipo "Sí o No", "Verdadero o Falso", "Activo o Inactivo".

Ejemplos:

|Variable|Valores posibles|
|---|---|
|¿Aprobó?|Sí / No|
|Cliente activo|Sí / No|
|Tiene licencia|Sí / No|

En programación muchas veces se representan mediante los valores **0 y 1**.

---

## Variables nominales

Las variables nominales contienen categorías que **no poseen un orden natural** entre ellas.

No existe una categoría mayor o menor que otra.

Ejemplos:

|Variable|Categorías|
|---|---|
|Color|Rojo, Azul, Verde|
|País|México, Canadá, Brasil|
|Sistema Operativo|Windows, Linux, macOS|

No tendría sentido afirmar que "Linux es mayor que Windows", ya que simplemente son categorías diferentes.

---

## Variables ordinales

Las variables ordinales contienen categorías que **sí poseen un orden lógico**, aunque la diferencia entre ellas no pueda medirse matemáticamente.

Ejemplos:

|Variable|Categorías|
|---|---|
|Nivel educativo|Primaria, Secundaria, Bachillerato, Universidad|
|Nivel de satisfacción|Muy malo, Malo, Regular, Bueno, Excelente|
|Riesgo|Bajo, Medio, Alto|

En este caso sí existe un orden, pero no puede afirmarse que "Excelente vale el doble que Bueno".

---

# Comparación entre variables

|Característica|Variables Numéricas|Variables Categóricas|
|---|---|---|
|Representan|Cantidades|Categorías|
|Se pueden sumar|Sí|No|
|Se calcula promedio|Sí|No|
|Se pueden ordenar|Generalmente sí|Solo las ordinales|
|Ejemplos|Edad, peso, salario|Color, género, carrera|

# Modelos descriptivos

Los **modelos descriptivos** tienen como objetivo comprender y resumir la información existente en un conjunto de datos. No buscan predecir el futuro, sino explicar qué ocurrió o cómo se comportan los datos.

Estos modelos responden preguntas como:

- ¿Cuál es el promedio de ventas?
- ¿Qué producto se vende más?
- ¿Cuál es la edad promedio de los clientes?
- ¿Qué porcentaje de alumnos aprobó?

Para ello utilizan herramientas estadísticas y gráficas como:

|Herramienta|Función|
|---|---|
|Promedio|Obtener el valor medio|
|Mediana|Encontrar el valor central|
|Moda|Identificar el valor más frecuente|
|Histogramas|Mostrar la distribución de datos|
|Gráficas de barras|Comparar categorías|
|Diagramas de dispersión|Analizar relaciones entre variables|

Por ejemplo, una empresa puede analizar todas las ventas del año para conocer cuáles fueron los meses con mayores ingresos.

---

# Modelos predictivos

Los **modelos predictivos** utilizan información histórica para estimar eventos futuros o clasificar nuevas observaciones.

Se basan en algoritmos de aprendizaje automático (Machine Learning) y modelos estadísticos que encuentran patrones dentro de los datos.

Estos modelos responden preguntas como:

- ¿Este cliente dejará de comprar?
- ¿Cuál será la demanda del próximo mes?
- ¿Un correo electrónico es spam?
- ¿Una transacción bancaria es fraudulenta?
- ¿Lloverá mañana?

Ejemplos de aplicaciones:

|Área|Predicción|
|---|---|
|Bancos|Riesgo de impago de un cliente|
|Comercio electrónico|Productos recomendados|
|Medicina|Probabilidad de desarrollar una enfermedad|
|Ciberseguridad|Detección de ataques informáticos|
|Finanzas|Predicción del precio de acciones|

Mientras los modelos descriptivos explican el pasado y el presente, los modelos predictivos intentan anticipar el futuro utilizando patrones aprendidos a partir de datos históricos.

# Transformar un conjunto de datos en conocimiento

Una de las frases más importantes del análisis de datos es:

> **"Transformar un conjunto de datos en conocimiento."**

Esto significa que los datos, por sí solos, tienen un valor limitado. El verdadero beneficio surge cuando esos datos se analizan e interpretan para generar información que facilite la toma de decisiones.

Este proceso puede entenderse mediante la siguiente secuencia:

|Etapa|Descripción|
|---|---|
|Datos|Valores sin procesar, como números, textos o registros.|
|Información|Datos organizados y con contexto que permiten comprender una situación.|
|Conocimiento|Interpretación de la información para identificar patrones, tendencias y relaciones útiles.|
|Decisión|Acción tomada con base en el conocimiento obtenido.|

Por ejemplo, una tienda registra diariamente miles de ventas. Esos registros son únicamente datos. Al calcular cuáles productos se venden más en determinadas temporadas, obtiene información. Si descubre que las ventas de paraguas aumentan considerablemente durante la temporada de lluvias, genera conocimiento sobre el comportamiento de sus clientes. Finalmente, utiliza ese conocimiento para aumentar el inventario antes de que comience la temporada, tomando una decisión fundamentada.

En la actualidad, el análisis de datos constituye la base de disciplinas como **Business Intelligence (BI)**, **Machine Learning**, **Big Data**, **Minería de Datos (Data Mining)** e **Inteligencia Artificial**, ya que todas ellas buscan extraer valor de grandes volúmenes de información para resolver problemas reales y apoyar la toma de decisiones basada en evidencia.
