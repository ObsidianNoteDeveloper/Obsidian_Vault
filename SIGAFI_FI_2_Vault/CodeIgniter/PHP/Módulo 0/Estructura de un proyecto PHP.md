

Una estructura de proyecto PHP óptima separa el código fuente privado de los archivos públicos.

La arquitectura de directorios recomendada para un proyecto web es la siguiente:

### Directorio Raíz  (`/`)

- `app/`
	- `Cotrollers/`
	- `Models/`
	- `Views/`
- `public/`
	- `index.php` 
	- `assets/`
	- `css/`
	- `js/`
	- `img/`
- `cofig/`
- `vendor/`
- `.htaccess`
- `composer.json`
