## Objetivo

Desarrollar un programa en JavaScript que simule el sistema de pedidos de una pequeña cafetería.

El programa deberá mostrar un menú de opciones y permitir al usuario realizar diferentes acciones hasta que decida salir.

---

# Ejemplo de ejecución

```
======== CAFETERÍA ========

1. Comprar café
2. Comprar té
3. Comprar pastel
4. Mostrar total
5. Reiniciar compra
6. Salir
   
Seleccione:
1

Se agregó un café.

Seleccione:
3

Se agregó un pastel.

Seleccione:
4

Productos: 2
Total: $105

Seleccione:
5

Compra reiniciada.

Seleccione:
4
No existen productos registrados.

Seleccione:
6

Gracias por su compra.
```
