

Digamos que se ha diseñado previamente una compuerta NAND de 3 entradas, denominada nand3, y ahora queremos utilizarla como parte de un nuevo diseño. Esto se ilustra en el código siguiente. La primera parte contiene la declaración del componente, que debe ser exactamente igual que en la entidad original. La segunda parte muestra la instanciación del componente, denominada nand_gate, con los puertos x1, x2, x3 y `y` actuales asignados a los puertos a1, a2, a3 y b originales, respectivamente.

```VHDL
-- component declaracion
component nand3 is
	port(a1, a2, a3: in std_logic;
		b: out std_logic);
	end component;

-- component instanciación 
nang_gate:nand3 port map(x1, x2, x3, y);
```

**OPCIONES DE MAPEO**

PORT MAP es simplemente una lista que relaciona los puertos del circuito real con los puertos del circuito real con los puertos del circuito prediseñado (componente que se está instanciando).

Este mapeo puede ser posicional o nominal, como se muestra en el ejemplo siguiente, que emplea nuevamente el circuito nand3.

```VHDL
--instanciacion componente
nand3_1: nand3 port map (x1, x2, x3, y); -- mapeo posicional
nand3_1: nand3 port map(a1=>x1, a2=>x2, a3=>x3, b=>y); --mapeo nominal
```

> [!Note] 
> Para proyectos grandes o con multiples equipos, el mapeo nominales preferibles.
> El mapeo posicional se usa más en ejemplos cortos o cuando el componente es muy simple y su orden de puertos es poco probable que cambie.

El siguiente circuito muestra un registro de desplazamiento circular con una secuencia rotatoria programable. Las entradas son `clk`, `load` y `d=d0 d1 d2 d3` y la última se utiliza para cargar la secuencia deseada en los `FF` cuando `load='1'`. La salida es `q= q0q1q2q3`, que muestra el valor instantaneo de la secuencia rotatoria. Observe que todas las celdas de este circuito son iguales y estan compuestas por un multiplexor más un `DFT`. Diseñe este circuito utilizando `COMPONENT` para instanciar los multiplexores y los `DFR`.

```VHDL
--Multiplexor
entity mux is
	port(a,b,sel: in bit;
		x: out bit);
end entity;
architecture mux of mux is
begin
	x <= a when sel = '0' else b;
end mux
```

```VHDL
-- FLIP.FLOP_D
entity, FFD is
	port(d, clk: in bit;
	q: out bit);
end entity;
architecture FF of FFD is
begin
	process(clk)
	begin
		if(clk event and clk = '1') then
			q <= d;
		end if;
	end process;
end FF;
```

```VHDL
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity registro_circular is
    port(
        clk  : in bit;
        load : in bit;
        d0, d1, d2, d3 : in bit;
        q0, q1, q2, q3 : out bit
    );
end registro_circular;


architecture Behavioral of registro_circular is

    -- Declaración del multiplexor
    component mux is
        port(
            a, b, sel : in bit;
            x         : out bit
        );
    end component;

    -- Declaración del flip-flop D
    component FFD is
        port(
            d, clk : in bit;
            q      : out bit
        );
    end component;

    -- Señales internas entre los MUX y los FFD
    signal m0, m1, m2, m3 : bit;

begin

    -- CELDA 0
    MUX0 : mux
        port map(
            a   => d0,
            b   => q3,
            sel => load,
            x   => m0
        );

    FF0 : FFD
        port map(
            d   => m0,
            clk => clk,
            q   => q0
        );


    -- CELDA 1
    MUX1 : mux
        port map(
            a   => d1,
            b   => q0,
            sel => load,
            x   => m1
        );

    FF1 : FFD
        port map(
            d   => m1,
            clk => clk,
            q   => q1
        );


    -- CELDA 2
    MUX2 : mux
        port map(
            a   => d2,
            b   => q1,
            sel => load,
            x   => m2
        );

    FF2 : FFD
        port map(
            d   => m2,
            clk => clk,
            q   => q2
        );


    -- CELDA 3
    MUX3 : mux
        port map(
            a   => d3,
            b   => q2,
            sel => load,
            x   => m3
        );

    FF3 : FFD
        port map(
            d   => m3,
            clk => clk,
            q   => q3
        );

end Behavioral;
```


Por tanto, las cuatro instancias deben quedar así:

```VHDL
MUX0 : mux
    port map(d0, q3, not load, m0);

MUX1 : mux
    port map(d1, q0, not load, m1);

MUX2 : mux
    port map(d2, q1, not load, m2);

MUX3 : mux
    port map(d3, q2, not load, m3);
```

**Esta es la versión que cumple exactamente el enunciado:** cuando `load='1'` se cargan `d0-d3`; cuando `load='0'`, se realiza el desplazamiento circular.

Contador de 0 a 9
Se diseña un contador (circuito convinacional) que convierta la salida de 4 bits del contador en na salida de 7 bit para alimentar un display 7 segmentos. Describa un código VHDL que implemente dicho circuito 

```VHDL
entity contador is
	generic(fclk: integer:=50_000_000); -- 50 MHz
	port(clk, rst: in bit;
	ssd : out bit_vector(6 downto 0));
end entity;

architecture behovioral contador is
begin
process(clk, rst)
	varaible contador_1: natural range 0 to fclk:=0;
	varaible contador_2: natural range 0 to 10:=0;
begin
if(rst='1') then
	contador_1:= 0;
	contador_2:= 0;
elsif(clk' event and clk='1')then
	contador_1:= contador_1 + 1;
	if(contador_1 = fclk)then
		contador_1:= 0;
		contador_2:= contador_2 + 1;
		if(contador_2 = 10) then
			contador_2:= 0;
		end if;
	end if;
end if;

case contador_2 is
	when 0 => ssd <= "0000001";
	when 1 => ssd <= "1001111";
	when 2 => ssd <= "0010010";
	when 3 => ssd <= "0000110";
	when 4 => ssd <= "1001100";
	when 5 => ssd <= "0100100";
	when 6 => ssd <= "0100000";
	when 7 => ssd <= "0001111";
	when 8 => ssd <= "0000000";
	when 9 => ssd <= "0000100";
	when other => ssd <= "0110000"
end case;
end process;
end behavioral;
```
