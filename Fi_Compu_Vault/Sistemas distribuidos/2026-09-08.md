
# Sistemas distribuidos 

**Arquitectura computacional**

- Unidad de procesamiento 
- Memoria de almacenamiento de datos (RAM)
- Memoria de instrucciones - ROM (EEPROM, ROM, PROM, EPROM Flash EPROM)
- Interconexiones (buses) -> datos, direcciones y control  {Número de bits que transporta el bus}
- E / S -> teclado, pantalla (LCD)
- Fuente de alimentación

> [!Note] 
> Los sistemas distribuidos son grafos, son sistemas complejos.

### Objetivo

- Importancia de los sistemas distribuidos en la sociedad actual
- Sus aspectos de diseño
- Sus principales retos tecnológicos

### Definición 

Un sistema distribuido es una colección de computadoras independientes que aparecen ante los usuarios como una única computadora.

Soportado por dos innovaciones clave:
- El microprocesador
- Las redes de área local
- Almacenamiento

### Ventajas frente a sistemas centralizados 

- Economía (mejor relación precio/rendimiento):
	- Los microprocesadores ofrecen una mejor relación precio/rendimiento que las computadoras centrales
	
- Mayor velocidad de cómputo:
	- Un sistema distribuido puede tener mayor poder de cómputo que una computadora centralizada individual
	
- Distribución inherente de aplicaciones:
	- Implica que un sistema distribuido puede emplear aplicaciones instaladas en computadoras remotas
	
- Confiabilidad (tolerancia a fallos parciales):
	- El sistema es consistente, aun si una computadora del sistema deja de funcionar
	
- Crecimiento proporcional:
	- Cada vez que se requiera mayor poder de cómputo en el sistema, sólo se pueden adicionar incrementos de cómputo requerido 

**Un sistema centralizado** es equivalente a una computadora individual

### Ventajas frente a computadoras aisladas

- Datos compartidos:
	- Permite que distintos usuarios tengan acceso a una base de datos (concurrencia en BD)
	
- Dispositivos compartidos (impresoras, plotters):
	- Permite compartir un recurso costoso entre distintos usuarios, como plotters o impresoras láser
	
- Comunicación (telnet, correo electrónico):
	- Brinda la posibilidad de comunicación de usuario a usuario como telnet, correo electrónico, etc.
	
- Flexibilidad y confiabilidad al repartir carga:
	- Facilita la repartición de carga de trabajo entre las distintas computadoras con base en sus funciones y capacidades, brindando una mayor flexibilidad del sistema (Balance de carga)
