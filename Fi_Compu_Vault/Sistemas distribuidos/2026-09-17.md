Sistemas operativos para sistemas distribuidos 

### Taxonomía 

Clasificación de sistemas distribuidos

- Sw debíl + Hw débil ( ej. Network File System (NFS))
	- SO de red
	- Sistema de archivo en red
- Sw fuerte + Hw fuerte ( ej. multiprocesadores)
	- Sistemas paralelos ( ej. Sistemas distribuidos de Clústeres)
	- SO multiprocesador
- Sw fuerte + Hw débil ( ej. sistemas realmente distribuidos)
	- Sistema único
	- Ej.
		- Conexión remota c/otras computadoras
		- Copia remota de archivos entre máquinas
		- Sistema de archivos global compartido


## Tipos de arquitecturas de Sistemas Distribuidos

Describen la organización lógica y Física

Un componente lógico es una unidad módular

**Organización Física**
- Pilas, Colas, Colas de prioridad, Listas enlazadas, Listas doblemente enlazadas, Árboles

Los conectores son mecanismos que hacen de mediadores de la comunicación, coordinación o cooperación entre componentes.

### Estilos de Arquitectura

A partir de interrelacionar componentes lógicos y conectores se pueden construir diferentes estilos de sistemas distribuidos.
- Arquitectura por capas
	- Las componentes lógicas se organizan por capas. 
	- Un componente lógico L_i sólo puede invocar operaciones en la capa de abajo L_i-1. En este estilo las invocaciones van de las capas superiores a inferiores 
	- Topología de red + Estilo arquitectónico (capas): Aplicación Servicios orientados a sistemas de archivos o datos.
	
- Arquitectura orientadas a componentes 
	- Cada objeto representa un componente lógico y los componentes están interconectados por invocaciones remotas (RPC). 
	- Ej. Un servicio solicita una operación a otro servicio remoto.
	
- Arquitectura orientada a los datos 
	- Este tipo de arquitectura va orientado a la ubicación o localidad de los datos, para reducir los costos de comunicación
	- Ej. Aplicaciones web distribuidas. Bases de datos distribuidas
	
- Arquitectura orientada a eventos.
	- Los componentes lógicos se comunican mediante eventos.
	- Los componentes publican eventos que solo son recibidos por aquellos componentes suscritos a ellos
	- Ej. Servicios de publicación y suscripción (notificaciones)
