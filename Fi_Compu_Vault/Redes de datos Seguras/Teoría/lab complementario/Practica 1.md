
# Cuestionario Previo 1

### 1. Defina el término norma.

Una **norma** es un conjunto de reglas, requisitos o indicaciones que se establecen para realizar una actividad de manera ordenada, segura y correcta. Su objetivo es establecer ciertos criterios que deben cumplirse para garantizar que los productos, servicios o procesos tengan determinadas características y un nivel de calidad. Las normas pueden ser creadas por organismos oficiales y, dependiendo de su naturaleza, pueden ser obligatorias o servir como referencia.

### 2. Defina el término estándar.

Un **estándar** es un conjunto de especificaciones, características o criterios que se utilizan como referencia para realizar, fabricar o evaluar algo de manera uniforme. Los estándares buscan que diferentes productos, equipos o sistemas puedan trabajar de forma compatible entre sí. Por ejemplo, en el área de redes existen estándares que indican cómo deben organizarse los cables para que diferentes dispositivos puedan comunicarse correctamente.

### 3. Indique si existe alguna diferencia entre normas y estándares. Justifique su respuesta.

Sí existe una diferencia, aunque ambos conceptos están muy relacionados. Una **norma** generalmente establece reglas o requisitos que deben cumplirse y puede tener un carácter obligatorio cuando es emitida o reconocida por una autoridad competente. Por otro lado, un **estándar** suele funcionar como una referencia técnica que indica cómo debe realizarse algo para mantener características de calidad, seguridad o compatibilidad. En términos sencillos, podemos decir que una norma establece **qué requisitos se deben cumplir**, mientras que un estándar puede establecer **cómo se debe realizar algo** para cumplir con determinadas características.

### 4. Mencione las ventajas y desventajas de utilizar normas.

Entre las principales **ventajas de utilizar normas** se encuentra que permiten trabajar de manera más ordenada y uniforme, ayudan a garantizar ciertos niveles de calidad y seguridad, facilitan la compatibilidad entre diferentes equipos y sistemas y permiten que distintas empresas utilicen criterios similares. También ayudan a reducir errores y problemas, ya que proporcionan procedimientos y requisitos previamente establecidos. Como **desventajas**, algunas normas pueden aumentar los costos debido a que cumplir con determinados requisitos puede requerir materiales, equipos o procedimientos específicos. Además, pueden limitar algunas opciones de diseño y, con el paso del tiempo, una norma puede quedar desactualizada cuando aparecen nuevas tecnologías.

### 5. ¿Qué nomenclatura emplean las normas en México?, describa la diferencia entre cada una de ellas.

En México existen diferentes tipos de normas y su nomenclatura permite identificar su naturaleza. Las principales son las **NOM**, que significa **Norma Oficial Mexicana**, y las **NMX**, que significa **Norma Mexicana**. Las NOM son regulaciones técnicas de carácter **obligatorio** que establecen requisitos que deben cumplirse para proteger aspectos como la seguridad, la salud, el medio ambiente o la calidad. Las NMX, en cambio, establecen especificaciones o características para productos, procesos o servicios y generalmente tienen un carácter **voluntario**, aunque pueden volverse obligatorias cuando una disposición legal o una NOM así lo establece. También pueden existir normas de referencia identificadas como **NRF**, utilizadas principalmente en determinados sectores, como el energético.

### 6. ¿Cuáles son las normas y estándares que se utilizan en México?

En México se utilizan tanto normas nacionales como estándares internacionales. Entre las principales normas nacionales se encuentran las **NOM y NMX**, dependiendo del área en la que se estén aplicando. En el área de tecnologías de la información y redes también se utilizan estándares desarrollados por organismos internacionales como **ISO, IEC, IEEE, ANSI y TIA**, debido a que permiten mantener compatibilidad entre equipos y sistemas fabricados por diferentes empresas. Por ejemplo, en redes de computadoras se emplean estándares relacionados con Ethernet, cableado estructurado, conectores y transmisión de datos.

### 7. ¿Qué nomenclatura emplea una norma internacional?

Las normas internacionales utilizan diferentes nomenclaturas dependiendo del organismo que las desarrolla. Por ejemplo, las normas desarrolladas por la **ISO** pueden identificarse como **ISO**, mientras que las desarrolladas conjuntamente por ISO e IEC utilizan la nomenclatura **ISO/IEC**. También existen estándares de organismos como **IEEE**, que utilizan el identificador IEEE seguido de un número, como **IEEE 802.3**, utilizado para Ethernet. En el caso de los estándares de cableado estructurado, también es común encontrar documentos identificados por **ANSI/TIA**, que indican que fueron desarrollados bajo el sistema de estandarización correspondiente a ANSI y TIA.

### 8. Indique las normas internacionales que se emplean para el cableado estructurado.

Para el **cableado estructurado** se utilizan principalmente estándares internacionales y norteamericanos que establecen las características que deben cumplir las instalaciones de redes. Entre los más importantes se encuentran la familia **ANSI/TIA-568**, que establece los requisitos para sistemas de cableado de telecomunicaciones; **ISO/IEC 11801**, que establece requisitos generales para el cableado genérico de las instalaciones de clientes; y **ANSI/TIA-569**, relacionada con los espacios y canalizaciones de telecomunicaciones. También se utilizan **ANSI/TIA-606**, que establece criterios para la administración y etiquetado de la infraestructura, y **ANSI/TIA-607**, relacionada con los sistemas de puesta a tierra y unión para telecomunicaciones. Estas normas y estándares permiten que una instalación de cableado sea organizada, segura, compatible y fácil de mantener.
