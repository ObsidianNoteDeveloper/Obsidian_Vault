### CSMA/CD y CSMA/CA

Subcapa MAC (IEEE 802)
- Entramado (framing)

El problema de Contención
- En medios de difusión (compartidos), cuando múltiples nodos transmiten simultáneamente se producen colisiones que destruyen las tramas, requiriendo un control distribuido. 

Concepto de CSMA
- Escuchan la portadora (Listen Before Talk)

**CSMA/CD o CSMA con detección de Colisiones** 
- Funcionamiento (mecanismo de contención)
	- Los dispositivos (NIC) escuchan el canal (medio) para detectar señales de otros dispositivos transmitiendo.
	- Si el canal estas libre, el dispositivo envía datos... 
	- Si se detecta ocupado ...
	- Si se detecta una colisión ...
	- Tras una colisión, se espera un tiempo aleatorio k. ...

#### Aplicaciones

CSMA/CD se utiliza en redes Ethernet, con operación en Semidúplex (Half-Duplex), en topologías compartidas mediante bus coaxial o concentradores (Hubs), donde los dispositivos no pueden enviar y recibir al mismo tiempo.

**CSMA/CA, o Acceso Múltiple con detección de Portadora y Evitación de colisiones**
- Es un método de acceso al medio utilizado en redes inalámbricas.

- Funcionamiento
	- Detección Física de Portadora
	- Detección Virtual de Portadora (NAV)
	- Temporizador de Retroceso (Random Backoff)

#### Aplicaciones

CSMA/CA es ampliamente utilizado en redes inalámbricas como Wi-Fi, Bluetooth y redes de área personal.

### Token

Un método de acceso al medio basado en un token, donde un token especial circula por la red

**Funcionamiento**
- Un dispositivo solo puede transmitir datos si tiene el token. Cuando un dispositivo termina de transmitir, pasa el token al siguiente dispositivo en la red.

**Detalles técnicos**
- El token es un pequeño paquete de datos que contiene información sobre el siguiente dispositivo en la red. El tamaño del token es pequeño para minimizar el tiempo de espera entre las transmisiones.

**Funcionamiento del Token**
- Paso1: El dispositivo con el token tiene permiso para trasmitir
- Paso 2:El token se pasa al siguiente dispositivo en el anillo
- Paso 3: El token continúa circulando por la red


### FDDI

Fiber Distributed Data Interface (Interfaz de datos distribuidos por fibra)

**Funcionamiento**
- FDDI utiliza dos anillos de fibra óptica que giran en direcciones opuestas.

**Detalles Técnicos**
- FDDI utiliza un método de acceso al medio basado en token. El token circula continuamente por la red, transmitiéndose de un dispositivo a otro.

**Formato de la trama**
- Preamble: Sincronización que indica en qué formato se envían los datos 
- Start delimiter: Marca el comienzo de la trama
- Frame control: Controlador de trama que indica el receptor si se trata de trama de datos o de control 
- Destination addres: Especifica la dirección del emisor.
- Source addres
- Payload: o carga útil es un campo que transporta los datos de la capa de red
- Checksum
- End delimiter
